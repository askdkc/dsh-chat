# DSH 普通聊天

[English](README.md) · [日本語](README.ja.md)

无需选择项目，即可在 DSH 中聊天。默认情况下，每个聊天都会在 `~/.dsh/` 下创建独立的工作目录。

## 安装

在 DSH 仓库根目录执行：

```sh
pnpm dsh plugin --profile web add @askdkc/dsh-chat
```

0.1.1 及后续版本无需修改 DSH 本体或应用补丁。

## 使用方法

启动或重启 DSH Web：

```sh
pnpm dsh web
```

1. 在浏览器中打开 DSH，点击 **普通聊天**，无需选择项目。
2. 如有需要，先在 DSH 设置中配置模型，然后发送消息。附件、工具和审批功能照常使用。
3. 点击对话标题旁的 **新建普通聊天**，即可创建另一个使用独立工作目录的聊天。

聊天统一显示在侧边栏的 **Regular Chat** 分组中，工作目录仍各自独立。删除该分组后，聊天记录会移至 **Ungrouped**，文件仍会保留。

重启 DSH 或卸载插件后，聊天记录和文件仍会保留。
