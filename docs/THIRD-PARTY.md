The Host bundle includes `resolveDshHome` and its pure helpers from the selected, unmodified official DeepSeek Harness checkout, `packages/util/home-paths/src/index.ts` (MIT; see DSH-LICENSE). `scripts/build-host.mjs` selects that checkout through `DSH_UPSTREAM`, defaulting to `.upstream`; it does not select an old commit or fetch a fixed resolver release. The current-upstream setup resolves the official default branch and records its revision in `dsh-revision-evidence.json`. The revision and bundle hashes actually verified for this change are recorded in CURRENT-UPSTREAM-VERIFICATION.md; they are build evidence, not compatibility gates. No substitute resolver implementation or separate home-paths runtime dependency is used.

For the recorded verification, the selected upstream home-paths package declares MIT and the included DSH-LICENSE matches the selected official repository LICENSE byte for byte. When preparing a release against a different upstream revision, verify its license and retain the required notices rather than assuming this historical verification applies to new source.

Both bundles contain Zod (MIT; see ZOD-LICENSE). React and Cordis are supplied by the DSH browser module table and are not bundled.
