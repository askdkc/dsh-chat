# DSH 通常チャット

[English](README.md) · [简体中文](README.zh.md)

中央の **通常チャット** から、プロジェクトを選ばずにDSH標準の会話を開始します。ヘッダーの **新しい通常チャット** は別の専用ディレクトリで会話を作ります。モデル・添付・履歴・ツール・承認はDSH標準を使います。

**本体パッチが必要です。** 対象は `deepseek-ai/deepseek-harness` の `d347e703908d0406b7a7ef80e3a0e594d86b2215`（ソース版 `0.1.3-alpha.1`）。PLAN.mdの経路Aを実装しています。未変更DSHへプラグインをインストールするだけでは中央ボタンは出ません。既存pickerを置換する経路Bは実装していません。

ビルド・パッチ適用・インストール手順は [英語README](README.md#build-and-install)、実行した試験と未検証事項は [検証記録](docs/VERIFICATION.md) に記載しています。配布tarballには `lib/` を含め、利用者側でのビルドや自動パッチ適用は行いません。この作業ではnpmへの公開はしていません。

実Loader検証により、PLANのinterceptor案は標準Gatewayと競合することが判明したため、同じ認証済み`/api`配下の公開Fetch経路を使用しています。[実装上の修正点](docs/IMPLEMENTATION.md) に根拠を記載しています。

保存先は接続先Hostの `$DSH_HOME/chat/sessions/session-<uuid>/workspace/` です。会話ログはDSHが保存します。再起動・無効化・アンインストールでファイルや会話を削除しません。

**再試行** は同じ要求・Session IDを再開します。tab単位のsessionStorageに復旧情報を保存し、再読込だけでは作成しません。作成中のtabを複製するとブラウザが復旧情報もコピーする場合があるため、同じ要求の再開になります。別画面へ移動した場合は遅延応答で選択を奪わず、**作成したチャットを開く** を表示します。ブラウザの保存機能が利用できない場合は作成を停止します。

保存領域の変更、壊れた記録、削除されたWorkspace・cwd、不正symlinkでは停止します。記録を消して無理に新規作成しないでください。複数Hostの書込みは拒否します。異常終了後のロック解除は、同じDSH_HOMEを使う全Hostの停止を確認し、`writer.lock/owner.json` のPIDを照合してから **`chat/state/writer.lock` だけ** を一意な退避名に移動します。`owner.json`、`requests/`、`sessions/` は保存してください。

専用cwdは相対ファイル名の衝突を防ぐもので、OSサンドボックスではありません。標準New Session・fork・subagentはcwdを引き継ぐ場合があります。新しい専用cwdを保証するのは本プラグインの専用操作だけです。モデル設定不足や認証不足はDSHの標準設定から解決します。

日本語が未登録なら追加し、DSH本体の未翻訳部分は英語にfallbackします。既存の日本語登録は削除しません。後から導入する言語パックも `ja` の既存登録を確認する必要があります。DSHが重複登録を拒否するため、他プラグインの無条件登録は救済できません。

NFS・複数Host・複数利用者・自動削除は非対応です。電源断耐性、Windows ACL、敵対的な同一ユーザーによるファイル差替え競合の防止は保証しません。
