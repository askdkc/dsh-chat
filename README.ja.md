# DSH 通常チャット

[English](README.md) · [简体中文](README.zh.md)

プロジェクトを選ばずにDSHでチャットできます。チャットごとの作業ディレクトリは、標準で `~/.dsh/` 配下に作成されます。

## インストール

DSHリポジトリ直下で実行します。

```sh
pnpm dsh plugin --profile web add @askdkc/dsh-chat
```

0.1.1以降はDSH本体の変更・パッチ適用は不要です。

## 使い方

DSH Webを起動、または再起動します。

```sh
pnpm dsh web
```

1. ブラウザでDSHを開き、**通常チャット** を押します。プロジェクトの選択は不要です。
2. 必要に応じてDSHの設定でモデルを選び、メッセージを送信します。添付・ツール・承認は通常どおり使えます。
3. 別の作業ディレクトリで会話を始めるには、ヘッダーの **新しい通常チャット** を押します。

チャットは左側の **Regular Chat** にまとまり、作業ディレクトリはチャットごとに分かれます。このグループを削除すると履歴は **Ungrouped** に移り、ファイルは残ります。

再起動やプラグインのアンインストール後も、会話履歴とファイルは残ります。
